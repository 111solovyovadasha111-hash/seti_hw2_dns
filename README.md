Реализован подход с ручным формированием запросов и ответов протокола DNS

Доп функционал:
* Поддержка нескольких типов записи
* ".multiply." в запросе

Использование:
```python server.py``` в одном терминале,
а в другом:
* ```dig -p 5300 @127.0.0.1 2.22.multiply.test.com```
* ```dig -p 5300 @127.0.0.1 insma.urfu.ru```
* ```dig -p 5300 @127.0.0.1 urfu.ru MX```
* ```dig -p 5300 @127.0.0.1 urfu.ru AAAA```
* ```dig -p 5300 @127.0.0.1 urfu.ru TXT```
